1Dataset

Sube un fichero o pega los datos. Cada fila se convierte en el state {"context": …, "record": {columna: valor}}. Marca solo las columnas que las preguntas necesitan: cada campo irrelevante resta precisión.

Formatos aceptados
  • CSV (.csv, .tsv, .txt): la primera fila es la cabecera con los nombres de columna. El separador (coma, punto y coma o tab) se detecta solo. Textos con comas o saltos de línea, entre comillas "…" (como exportan Excel y Google Sheets).
  • JSON: una lista de objetos, [{"subject": "…", "message": "…"}, …], o {"rows": [ … ]}. Los valores anidados se envían tal cual dentro de record.
  • JSONL: un objeto JSON por línea.

Codificación UTF-8 (en Excel: "CSV UTF-8"); con otra, los acentos pueden salir mal. No se aceptan .xlsx ni parquet: guárdalos antes como CSV. No hace falta limpiar el fichero: las columnas se eligen abajo (desmarca IDs y la columna de la etiqueta si el dataset está etiquetado). Las columnas label o label_* empiezan desmarcadas. Sin límite de filas; a partir de unos ~5 MB la página no puede recordar las filas al recargar (las preguntas sí).
